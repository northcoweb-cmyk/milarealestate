# 50 things to run through Mila

Addresses are real places in different states. Most are landmarks or public buildings I'm confident exist, so they test address handling, saving and scheduling. For home details (beds, baths, price) swap in a real listing you pull from Zillow or the MLS, because Mila's data lookups are for homes. Date and time answers use "Saturday" and "tomorrow", so run them any day.

Pass means: Mila understands it in one message, never asks "who is it for" when it's a property, never invents facts she doesn't have, and asks before anything goes out. Tap 🐞 on anything that fails.
