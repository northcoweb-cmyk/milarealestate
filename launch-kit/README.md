# Mila launch kit

- `logo/` — wordmark (white / black on transparent, white on the brand gradient) and the app icon (512, 1024). Wordmark font: Instrument Serif.
- `app-screens/` — real iPhone-size (1170x2532) screenshots of the app: home, chat (listing brief), properties, content, calendar, contacts. Property photos are not included: use your own 4–6 images where the video shows listing photos.
- Brand: gradient `#8fb4ff → #a68cff → #ffc9a8`, ink `#0a0a0a`, fonts Instrument Serif (display) + Inter (UI).
